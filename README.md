# Универсальная кастомная карта (Leaflet, полностью бесплатно)

Карта + поиск адреса с нормализацией + клик-геокодинг. **Ноль
ключей, ноль привязанных карт/биллинга, ноль подписок.** Никакой
специфики "пунктов выдачи" — компонент общего назначения.

## Установка и запуск

```bash
npm install
npm run dev
```

Всё. Никакого `.env`, никакой регистрации где-либо не требуется.

## Почему Leaflet, а не MapLibre/Google

Предыдущие попытки — MapLibre GL JS с цепочкой из трёх разных
провайдеров векторных/растровых тайлов (MapTiler, OpenFreeMap, сырой
OSM) — подряд не смогли догрузить тайлы в конкретной сети, хотя
обычные JSON-запросы (геокодинг) проходили нормально. Похоже на
фильтрацию именно тайлового трафика через `fetch()`.

Google Maps работал бы, но требует привязанный биллинг-аккаунт — не
подходит, если задача принципиально "без карты вообще".

**Leaflet — другой путь**: он грузит тайлы как обычные `<img>`-теги
браузера, а не через `fetch()`, как MapLibre. Это другой сетевой
паттерн запроса, который часто проходит там, где резались `fetch()`-
запросы к тем же типам CDN. Плюс он в разы легче (без WebGL-движка).

## Цепочка из 6 бесплатных провайдеров тайлов (без ключей)

Порядок — от самого современного вида к самому надёжному:

1. **CARTO Voyager** — современный цветной стиль (по умолчанию)
2. **CARTO Positron** — чистый светлый минимализм
3. **OpenStreetMap** — классический вид (тонкие линии, цвета из
   2010-х), зато самый надёжный хостинг — сам фонд OSM
4. **Esri World Street Map** — крупная корпоративная инфраструктура
5. **Wikimedia Maps** — тот же домен, что у Википедии
6. **OpenTopoMap** — топографический, вариант последней надежды

Если один недоступен — карта автоматически пробует следующего.
Баннер наверху показывает, если произошло именно автоматическое
переключение из-за сбоя (не мешает при ручном выборе).

**Плюс кнопка ручного переключения** (иконка слоёв справа под
зум-контролами) — можно самостоятельно выбрать любой из 6 стилей,
не дожидаясь автоматического фолбэка, если текущий вид не нравится.

## Геокодинг — тоже бесплатно, без ключа

`createNominatimProvider` (используется по умолчанию в `App.jsx`) —
на базе OpenStreetMap, работает глобально (в т.ч. Казахстан), без
ключа и без привязки карты. Официальный лимит — ~1 запрос/сек для
серьёзной прод-нагрузки с фронта; для такого трафика проксируйте
через свой бэкенд с кэшем.

В `geocodeProviders.js` также остался `createMapTilerProvider` —
опциональный вариант с более щедрыми лимитами и структурированной
нормализацией, требует бесплатный ключ, но **без** привязки карты/
биллинга (в отличие от Google). Не обязателен, просто альтернатива.

## Структура

| Файл | Назначение |
|---|---|
| `App.jsx` | Точка входа, создаёт Nominatim-геокодер |
| `components/CustomMap/CustomMap.jsx` | Карта на Leaflet, поиск, клик-геокодинг, карточка адреса |
| `components/CustomMap/tileProviders.js` | Цепочка из 5 бесплатных тайл-провайдеров + логика фолбэка |
| `components/CustomMap/geocodeProviders.js` | Nominatim (по умолчанию) + опционально MapTiler |
| `components/CustomMap/useGeocoder.js` | Хук поиска с debounce |

## Кастомизация внешнего вида

Свой пин — SVG в виде Leaflet `divIcon` в `CustomMap.jsx`
(`PIN_ICON`), цвет берётся из CSS-переменной `--cm-accent` в
`CustomMap.css` — там же дизайн поисковой строки и карточки адреса.

Растровые тайлы (в отличие от векторных) нельзя перекрасить на лету —
если нужен свой цвет дорог/воды прямо в тайлах, а не только в UI
поверх карты, это уже требует векторного стиля (MapLibre + ключ от
MapTiler) — компромисс между "бесплатно и просто" и "полный контроль
над каждым пикселем карты".
